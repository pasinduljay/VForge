## 2. External Operational Items Classified as `NOT VERIFIABLE` Locally

To preserve strict engineering honesty (§32 of `docs/DEVELOPMENT_ROADMAP.md`), the following operational deployment milestones are classified as **`NOT VERIFIABLE`** in a single-host local development environment and are tracked in [`docs/PRODUCTION_READINESS_ASSESSMENT.md`](PRODUCTION_READINESS_ASSESSMENT.md):

1. **Multi-Node Production Cluster Deployment:** Live deployment across physically separated Control Plane and Linux Execution Plane hosts behind an enterprise TLS 1.3 ingress controller.
2. **Live External OpenBao / Hardware HSM Integration:** Connecting `OpenBaoProvider` to a production HA OpenBao/Vault cluster backed by cloud KMS/HSM auto-unseal.
3. **Live External OIDC Enterprise IdP Integration:** End-to-end browser login against a production corporate IdP (Okta, Microsoft Entra ID, or HA Keycloak) over public/enterprise DNS.
4. **Off-Site WORM Disaster Recovery Storage:** Replicating encrypted DR archives to remote S3 Object Lock / immutable cloud storage and executing cross-region failover.
5. **Third-Party External Penetration Test & FIPS 140-3 Module Validation:** Independent external human red-team assessment and accredited cryptographic module certification.
